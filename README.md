| Page           | Address                                  | Linked from                                             |
| -------------- | ---------------------------------------- | ------------------------------------------------------- |

The addresses are permanent: they are in Google's settings, the stores and the app. Don't rename or move the files.

Plain HTML and one stylesheet, no build step. Pages publishes `main` from the root folder. The `google*.html` file,
once added, proves the site to Google Search Console; keep it.
